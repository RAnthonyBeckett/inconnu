# Grapevine attribution and license

Inconnu is based on Grapevine by Adam Cerling.

Grapevine, the LARP Administration Utility, was written by Adam Cerling. When
he stopped maintaining it, he released the Grapevine 3.01 source code to the
community with the following statement:

> This Creative Commons Attribution-NonCommercial License 2.5 accompanies the
> Grapevine 3.01 source code distributed by Adam Cerling. Derivative works
> based on this source code should include attribution to the effect of
> "based on Grapevine by Adam Cerling." Derivative works should also include
> this license, including whatever attribution you wish to add for your work.

The license is Creative Commons Attribution-NonCommercial 2.5:
https://creativecommons.org/licenses/by-nc/2.5/legalcode

A preserved copy of the released source and its license file is at
https://github.com/soulhakr/iGrapevine/tree/master/GV301Source

Inconnu is a rebuild of Grapevine in Rust. It reads Grapevine's file formats,
and the Grapevine source and menu files were used as reference during the
rebuild. Our thanks to Adam Cerling for making Grapevine and for leaving it
to the community.
