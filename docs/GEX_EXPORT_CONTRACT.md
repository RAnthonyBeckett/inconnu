# Grapevine v3 XML transfer contract

This source adds a bounded legacy XML projection to the saved-sheet print/export window. It does not replace a library backup. The current release executable is unchanged until a later build/release gate.

- Public output is the default. Private Storyteller output requires the local Storyteller role; local roles are not authentication.
- Preview the export summary before writing. Character, roster and Chronicle projection are separate choices. A changed library revision, changed options or changed target invalidates the preview. Writing regenerates the projection and uses atomic no-overwrite publication.
- UTF-8 output has an explicit encoding declaration and an unnamespaced `grapevine version="3"` root. XML attributes/text are escaped; unsupported controls are removed and reported. Typography normalization is optional and default-on. It preserves accented/non-Latin letters. Identifiers are escaped without typography changes; identifiers requiring redaction/control removal fail closed.
- Public projection excludes originals, private fields, notes, contacts, internal receipts/audit/approval data and private story records. Standard/custom marker redaction runs to a fixed point before and after normalization. Only allowlisted fields and known nested elements are emitted.
- Risen defaults to Disallow. Explicit ExportAsWraith emits the original `wraith ethnos="Risen"` representation, which Inconnu recognizes on import. Explicit ExportAsVarious emits `various`; re-import has kind Various. Both modes preserve additional list XML and warn that original recipients may ignore lists outside their native type. No `risen` element is invented.
- Additive record attributes `inconnupublic` and `inconnuprivate` declare field visibility for Inconnu-to-Inconnu transfers. Public declarations are restricted to known sheet identity/resource/list keys and still undergo redaction. Private declarations override public declarations. Malformed declarations fail closed. Other legacy applications may ignore this metadata; keep private transfers private and review recipient visibility.
- Ordinary third-party XML retains its historical list normalization shape. New declared Inconnu lists can round-trip directly; legacy common lists retained under UnmappedTraitLists remain available through the existing conservative sheet backfill. Missing trait `val` defaults to `1`, matching the original reader.
- Known nested legacy story fields are projected through context-specific element/attribute whitelists, including action/result text, plot developments, rumor bodies, query clauses and effect links. Current typed Action/Plot/Rumor edits override their retained source fields. Unknown fields/structures produce omission warnings, including per-record field names where available.
- Chronicle projection includes supported records and profile details. Retained calendar/APR sources, scheduled sessions and application-only workflows are not currently included. These exclusions are the approved final transfer scope. Complete Chronicle backups and binary-date conversion are outside Phase 2.
- Source dates and other unsupported scalar structures may fail closed rather than be guessed. Full binary-date and Chronicle coverage require further source-specific proof.
- Limits: 10,000 records, 32 MiB XML, 64 KiB individual text, 4,096 trait/nested rows, 16 emitted nested levels, 64 distinct custom marker pairs, and bounded input projection maps. Original payloads are not serialized.

Synthetic round-trip proof uses both grapevine-legacy-reader and importer::normalize. No live Haller upload or acceptance is claimed. No external service or account is required at runtime.
