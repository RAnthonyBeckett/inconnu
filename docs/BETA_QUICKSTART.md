# Inconnu 0.48.0-beta.4 — Windows beta

This beta supports local testing of the reviewed creature profiles. Inconnu is not officially
sponsored or supported by OWbN (maybe one day!), and this beta does not claim complete rules, content or original Grapevine parity.

## Start

Extract the entire ZIP into a folder you can write to. Open **Open Inconnu.cmd**; it starts
**Inconnu.exe**.
No Rust installation, VM, cloud account or subscription is needed. Create a local library
or open a testing copy. In Storyteller, preview/import a GEX or GV3; source files are retained
unchanged. Recent libraries remembers opened library paths; Forget/Clear keeps the files.

Use a copy for beta testing. A library and its backups contain private game information.
The included Synthetic Examples are fabricated and suitable for a first look.

## Try the useful routes

- Import a roster, open a character, edit and save, close and reopen the library.
- Choose a reviewed creature profile, then review starting traits, powers and entering-play status.
- Record an explicit XP opening; preview spending and combined saved plans, including
  out-of-clan costs. Review attendance/group awards, corrections and the no-negative ledger.
- Open XP-versus-playtime review, classify awards explicitly and save private choices.
  Reopen/load them: exact choices return, new/changed awards stay unclassified, and policy /
  eligibility confirmations require a fresh review. Separate-review awards are not exemptions.
- Preview a Player sheet in English or Português, optionally including supported simple
  mechanics. Review legacy game details/calendar plans; calendar import grants no attendance/XP.
- Back up the testing library, make a test change, restore and confirm the original state.

## Shared profile forms

Reviewed creation and catalogue purchases cover Vampire, Werewolf, Mortal, Changeling,
Wraith, Mage, Fera, Mummy, Kuei-Jin, Hunter, Demon, and Risen. Various is the local-rules
umbrella and requires its own Storyteller configuration. The profiles cover defined
starting templates and powers, including Gurahl Fera and first-Balance Amenti. Hunter
uses a locally adopted 2021 Imbued packet and legacy menu baseline. Individual MET
book citations from Laws of the Reckoning (#5037) are pending.

Storytellers can export Haller-safe .gex XML, enable OWbN Character and Mechanics
Bylaws checks with packet authority, and load House Rules Packs. The packs configure
Challenge Pool Math for sheets. Export a Player Mobile Sheet Bundle as
.inconnu-sheet.json for a portable sheet without private Storyteller data.

## Known beta limits

The target is local play on Windows. Network identity and direct game or organization
sharing remain future work. Local work modes are not authentication.
Automatic rules/prerequisites and content coverage are partial. Forty supported MET powers
have optional mechanics. Source catalogues cover selected names, ranks and provenance across editions.
The display identifies native MET tiers and explicitly converted levels. Unsupported/exceptional cases need explicit staff
review; imported labels are not verified rules. Source books are not bundled.

Monthly limits use a qualified saved policy snapshot and manual applicability/eligibility
review; the tool does not approve awards, exceptions, misconduct findings or transfers.
Binary-calendar extraction has reader-shape/date-oracle coverage; real legacy calendar /
locale parity still needs testing. Fluent Portuguese, broader accessibility, long-running /
other-machine behavior and whole-app manual acceptance remain beta feedback areas.

## If something fails

Leave the error dialog open long enough to capture its text/code. Storyteller > Diagnostics
provides local logs and a reviewed support export. Inspect the proposed contents before
sharing; include the beta version, steps, expected/actual result and error code. Keep real
character data, contacts and private evidence out of public reports. Nothing is sent
automatically. Preserve the testing library and trace when a repeatable failure occurs.
