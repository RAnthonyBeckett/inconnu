# Inconnu 0.48.0-beta.4 validation and limits

The beta is checked with Rust service/integration tests, strict Clippy and formatting,
synthetic same-character creation/advancement/audit/recovery, package manifests, and standalone Windows UI
checks at two text sizes. The 152-check Windows proof at 100% and 125% is from beta.3. Public packages omit raw machine-specific logs.
Compiler paths are remapped and source/runtime package contents are checked for private
workspace paths before upload. Only fabricated fixtures are distributed.

These checks do not prove full legacy parity, all-rule coverage, fluent Portuguese,
long-session/accessibility/other-machine acceptance or official organization approval.
See BETA_QUICKSTART.md for beta feedback areas. Do not use test results as authority to
approve XP, exceptions, transfers or rules. Keep real libraries and evidence private.

The shared configuration refactor also checks all thirteen kinds through the same synthetic
primary/secondary power purchase and original-cost refund path. Creation/profile bounds,
source validation, bilingual form state and private draft exclusion are tested. Legacy
Vampire wire and source-fact hash tests remain unchanged. ASCII custom Storyteller markers
match case-insensitively with Unicode-safe boundaries; non-ASCII markers retain exact matching.

Reviewed creation and catalogue purchases cover Vampire, Werewolf, Mortal, Changeling,
Wraith, Mage, Fera, Mummy, Kuei-Jin, Hunter, Demon, and Risen. Various is the local-rules
umbrella and requires its own Storyteller configuration. The profiles cover defined
starting templates and powers, including Gurahl Fera and first-Balance Amenti. Hunter
uses a locally adopted 2021 Imbued packet and legacy menu baseline. Individual MET
book citations from Laws of the Reckoning (#5037) are pending.

Storytellers can export Haller-safe .gex XML, enable OWbN Character and Mechanics
Bylaws checks with packet authority, and load House Rules Packs. The packs configure
Challenge Pool Math for sheets. Export a Player Mobile Sheet Bundle as
.inconnu-sheet.json for a portable sheet without private Storyteller data.
